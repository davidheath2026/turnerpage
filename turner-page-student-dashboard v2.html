SQL Server Migration Assistant v10.5 ships with Copilot-assisted conversion ↗

Microsoft's database migration tool now uses Copilot to help convert SAP ASE (Sybase) code to SQL Server and Azure SQL, plus more reliable Oracle-to-Managed-Instance procedure handling.

Microsoft Tech Community · Feb 12, 2026
🧩
Fabric named the control plane for Microsoft's whole data estate ↗

At the joint FabCon/SQLCon 2026 keynote, Microsoft introduced new migration assistants that move Azure Data Factory pipelines and SQL databases directly into Fabric — worth knowing if a client's target platform is shifting under you.

Microsoft Azure Blog · Mar 18, 2026
📦
Migration Assistant for Fabric Data Warehouse gets a major update ↗

A cited customer case moved 300+ pipelines and 500 tables into Fabric with far less manual rework, as Microsoft expands the guided migration path for Synapse and SQL Server workloads.

Microsoft Fabric Blog · Jun 3, 2026

Data Warehouse Migration specialization folded into a new Analytics track ↗

Microsoft is consolidating partner specializations — Data Warehouse Migration to Azure and Business Intelligence now sit under a single Analytics on Microsoft Azure specialization, with existing partners auto-enrolled.

Microsoft Learn — Partner Center · Effective Aug 2026
